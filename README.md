# Campus Bites

Campus Bites is a simple informational website for a university cafeteria. It helps students and staff explore the food menu, daily deals, ordering process, and contact information.

## Website Pages

- Home
- Menu
- Daily Deals
- How to Order
- Feedback & Contact

## Technologies Used

- HTML
- CSS

## Project Structure

- src/ - Contains all HTML pages.
- styles/ - Contains the shared CSS file.
